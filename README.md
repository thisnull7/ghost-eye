## 👁️ TENTANG

**GHOST EYE** adalah tools forensik gambar berbasis terminal. Dirancang untuk mengekstrak setiap informasi yang tersembunyi dalam sebuah file gambar. Dari metadata EXIF, koordinat GPS, hingga analisis manipulasi. Cukup masukkan nama gambar, Ghost Eye akan membongkar semuanya.

**Dibangun untuk mengungkap kebenaran di balik setiap piksel.**

---

## 🎯 FITUR UTAMA

| Fitur | Deskripsi |
|-------|-----------|
| 📁 **Informasi File** | Nama, ukuran, format, dimensi, hash MD5 & SHA-256 |
| 📷 **Metadata EXIF** | Kamera, lensa, software edit, timestamp, ISO, shutter speed |
| 📍 **GPS Tracking** | Koordinat, Google Maps link, Street View, alamat lengkap |
| 🗺️ **Geolokasi** | Negara, provinsi, kota, jalan, kode pos via OpenStreetMap |
| 🔍 **Deteksi Manipulasi** | Skor manipulasi, flags editing software, timestamp hilang |
| 🎨 **Analisis Warna** | RGB rata-rata, brightness, light/dark detection |
| ⚡ **Input Sederhana** | Cukup ketik nama file gambar tanpa path |

## 🛠️ INSTALASI

### Prasyarat
- **Python 3.7+** terinstal di sistem
- **Git** untuk cloning repositori

### Langkah Instalasi

```bash
# Clone repositori
git clone https://github.com/thisnull7/ghost-eye.git

# Masuk ke direktori
cd ghost-eye

# Install dependensi
pip install -r requirements.txt

🚀 CARA MENJALANKAN

python main.py

Masukkan nama gambar saat diminta. Pastikan gambar berada di folder yang sama dengan main.py.
